存股評分表 稅效退稅 + 高點防災 版本 2026-07-17b

總分 = 稅效股利 + 填息力 + 防禦抗跌 + 品質,四支柱權重可用下方滑桿自己調。每項先換成固定級距分數再加權,單一項目不會主導。買進訊號要求「不貴」——高點時系統傾向叫你等,而不是追。點任一檔的「建議」標籤會彈出行動卡:該買/賣的價位、判斷理由、你的部位與稅務提醒。

稅效股利盈餘現金殖利率只算「盈餘配息」(可抵 8.5% 稅、減資/公積不算):4.5%→8 分、6%→滿分,>7.5% 反而扣(常不可持續)
配息率健康40–70% 甜蜜區滿分;>100% 或 EPS 虧損趨近 0
連續配息年數≥10 年滿分
填息力填息率(近5次)領息不填息=課稅又賠價差。填息比例越高越好
填息速度越快越好,≤10 天滿分、180 天→0
防禦抗跌相對便宜度現殖利率 ÷ 自己5年平均:≥1 表示比平常便宜(高點防災核心)。<0.9 標「偏貴」
低波動近3年年化波動,越低越防禦
抗跌近5年最大回撤,跌得越淺越好
品質ROE近四季稅後淨利/股東權益,≥15% 佳、≥25% 滿分
淨利率≥15% 滿分

品質閘門:非金融/ETF 若 ROE<8% → 總分封頂 55(擋高息價值陷阱)。缺資料給該項中性 5 分。金融股不評 ROE、ETF 只評收益,結構性弱項自動中性。

價格帶(自身殖利率帶):便宜價=近12月現金股利÷(自身5年平均殖利率×1.3)、合理價=÷1.0、貴價=÷0.9——即「殖利率回到這檔自己的歷史常態」的價位,與你原 Excel 買進/賣出價同一邏輯。每檔用自己的常態,存股用存股的尺、成長股用成長股的尺,不會再出現「台積電要跌回 236」的荒謬目標。近12月無配息者退回「5年均息×16/20/25」估算並標註。持有價欄可直接在表格內輸入你的成本,行動卡會用它算損益。

建議:近四季EPS<0 或總分<40→賣出;總分與便宜度過門檻→買進;盈餘殖利率>4% 且已公告發放日在未來→配息;總分≥55 但偏貴→觀察(偏貴);總分≥55→持有;其餘→觀察。

市場溫度計 v2(馬克斯週期,雙軸:溫度=條件、趨勢燈=引信):溫度三指標——指數 200 日乖離(量表延伸至 +50%,不再頂格失真)、槓桿溫度(融資原始增速與「超額槓桿=融資增速−指數漲幅」各半:漲勢若非融資推動,溫度應誠實反映)、股票池便宜度中位數(EPS 成長中位數為正時給最多 −10 度減溫,盈餘推的漲不同於本夢比推的漲)。趨勢燈獨立於溫度:完好(在60日線上且距高點<8%)/轉弱/破壞(跌破200日線)。

溫度只說「摔下來會多痛」,趨勢燈才說「開始摔了沒」。檔位:低溫<25:買進門檻 0.85+60、回溫:0.95+65、偏熱:1.05+70、過熱+趨勢完好:停發一般買進,僅留嚴選門(便宜度≥1.1 且總分≥75 且填息率≥0.6 →「買進(嚴選)」)、過熱(不論趨勢):總分<55 且便宜度<0.5 →「減碼(過熱)」,趁強出貨、過熱+趨勢轉弱:貴且填息差的持股亮「減碼」、過熱+趨勢破壞:便宜度<0.8 全亮「減碼」。賣出的階梯:賣出=個股本身壞了(虧損或總分<40),與市場冷熱無關;減碼(過熱)=個股沒壞但「平庸+極貴」,趁趨勢還在時分批降低曝險;減碼=引信點燃後的防禦執行。按「完整更新」連同溫度計刷新。
