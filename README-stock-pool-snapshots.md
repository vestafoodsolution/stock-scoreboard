# 股票池快照：Codex 定時更新說明

這是安全的「可由 Codex 定時執行」版本。GitHub repository **不包含 GitHub Actions 工作流程**；更新時間、是否執行與是否推送，都由 Codex 依另行確認的排程管理。更新器唯一可寫入的正式資料檔是 `data/stock-pool-snapshot.json`；它不再寫入 `index.html` 或 `morning.html`。

## 它每天更新什麼

- 固定 59 檔名單的日收盤價（TWSE 與 TPEx，日更）；官方個股缺檔時，以同一交易日的 FinMind `TaiwanStockPrice` 補齊，不拿前一日價格冒充當日收盤。
- 每檔的相對便宜度，以及其全池中位數。
- 非 ETF 成員的 FinMind 季度 EPS、EPS 成長率（AK）與 EPS 成長中位數（季更）。

日更不抓財報、不猜 EPS。便宜度的定義是「近一年股利殖利率 ÷ 五年平均殖利率」；每次以當日有效收盤價直接重算股利率與便宜度：

`新便宜度 =（近一年股利 ÷ 當日收盤價）÷ 五年平均殖利率`

季更使用現有網頁 `computeJS()` 相同的定義：最近四季 EPS 合計 ÷ 前四季 EPS 合計 − 1；若前四季合計不大於零，該檔 AK 為空值、不納入中位數。ETF 沿用既有「無 EPS」設定。國巨等發生面額／股數變更的公司會先將前後期每股數字調整到相同比較基準。季度快照會寫入財報資料日、期間結束日與下一法定公告期限。

59 檔名單必須完整且不得重複；股價補檔後仍必須 59/59 才能產生、寫入或推送日更快照。任何一檔官方與 FinMind 都沒有可用價格時，流程直接失敗並保留上一份快照，不以最後已知值冒充本次資料。

## 怎麼先驗證

在專案根目錄執行：

```bash
node scripts/update-stock-pool.mjs --self-test
node test/update-stock-pool.test.mjs
node scripts/update-stock-pool.mjs --target=price --date=2026-07-29
node scripts/update-stock-pool.mjs --target=fundamentals --date=2026-05-10
```

後兩行都是預設乾跑：日更先驗證官方價格，再以同日 FinMind `TaiwanStockPrice` 補齊官方缺檔，並要求 59/59；季更選擇最新共同完整八季期末。固定名單不符、在當日 14:00 前誤跑、價格補檔後仍非 59/59、資料格式改變或無有效中位數時，流程直接失敗且不寫檔。

確認輸出與網站畫面後，才由 Codex 在已獲確認的定時工作中，以 `--write` 執行對應目標。它只會以同目錄暫存檔＋原子替換寫入單一 JSON 快照；兩個頁面都讀取這份檔案。快照不存在、無法讀取、格式不對或網路失敗時，頁面會保留各自原本嵌入的快照。更新器本身不會提交、推送或發布；這些外部動作必須另行確認。

## 何時才可啟用 Codex 每日定時更新

必須同時完成：

1. 已連續人工乾跑至少 5 個台股開市日，均達 59/59。
2. 人工檢查至少一檔價格變動時，便宜度確實按上式變動。
3. 已補上可信財報來源的 `asOf`、`periodEnd`、`validUntil`；否則晨報不應產出正式三因子溫度。
4. 同意由專人檢閱變更、提交與發布的責任分工。

目前尚未建立或啟用任何定時工作；不可只因腳本存在就把它打開。定時工作建立後，仍應依上述條件先乾跑與驗證，並保留人工檢閱、提交與發布的責任分工。
